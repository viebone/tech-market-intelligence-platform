I want to build a mechanism that allows users to provide feedback, at product level and
feature level.

- On the left navigation, after the data stories, in a way that's always visible at the
  bottom of that panel: an option to provide feedback about the tool, with a nice message.
  On click it should show a 1-5 "How satisfied are you with this platform?" rating (mandatory)
  and a second, non-mandatory free-text area to provide written feedback.
- On each Data Story, at the bottom: thumbs up and thumbs down. If the user clicks thumbs
  down, we capture that, and it also opens the option to provide written feedback, which we
  should capture.
- All of this should be captured and accessible in the admin: "User Feedback", showing the
  average rating for the platform, the average/aggregate for each ratable feature, and then
  each individual answer with its rating (or thumbs up/down) and the written feedback, if any.
