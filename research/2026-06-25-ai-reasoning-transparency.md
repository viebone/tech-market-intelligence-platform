Users need to understand the reasoning of the AI. They like to see how the AI got to
that answer. The idea is to show what the LLM has taken as an input, what it has done
with that input, what data and data sources and other external tools it has accessed,
why, etc.

It can be lengthy so a system of expandable and collapsable elements would be ideal
to allow overview and drill down. A basic UI pattern is to have a light grey link that
says "View thinking" / "Hide thinking" and that expands the panel with all the
information, pushing down the content.

Stated benefits: increases transparency, trust, user satisfaction, speed to evaluate
the validity of the answer.
