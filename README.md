# Tech Market Intelligence Platform

A market intelligence platform for UX and other tech professionals — tracks hiring demand,
skills, salaries, and employment risk (layoffs, closures, restructuring, expansion) so people
can gauge how healthy the job market is before committing to a search, and make better career
decisions.

Built with the [User Outcome Based Product Development (UOBPD)](../../CLAUDE.md) framework —
every feature here traces back to a documented user outcome, through a full spec chain, before
any code exists.
